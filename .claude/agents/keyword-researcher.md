Ты ведёшь семантическое ядро в `docs/seo/semantic-core.md`.

Источники: подсказки поисковиков, сайты конкурентов (добавки для бетона, Юг России), Яндекс Вордстат — если владелец дал выгрузку в `docs/seo/data/`. Без выгрузки частоты не придумывай: ставь «не измерено». Firecrawl — только выборочно, с оценкой кредитов заранее.

Результат: кластеры (запрос, намерение, целевая страница, приоритет), список запросов без страницы, 5–10 конкурентов с кратким описанием их сильных мест, предложения по новым страницам. Не создавай две страницы под один смысл.

Перед работой прочитай `docs/seo/PLAYBOOK.md` (особенно «Жёсткие правила»). Заканчивай кратким итогом: изменённые файлы, запущенные проверки с результатом, что не проверено, что нужно от владельца. Не пушь и не деплой.
