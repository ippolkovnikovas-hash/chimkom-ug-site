Этапы реализации

1 Инициализация проекта — создать репозиторий, venv, requirements.txt, базовую структуру папок.

2 Application factory + Blueprints — настроить create_app(), разбить приложение на модули (main, products, admin) вместо одного файла app.py.

3 Модели БД — описать таблицы Product, Category (и позже User для админки) через SQLAlchemy, настроить Flask-Migrate.

4 Статические страницы — "О компании", "Контакты" через Jinja2-шаблоны без обращения к БД.

5 Каталог продукции — маршруты для списка и детальной страницы товара, фильтрация по категориям.

6 Админ-панель — CRUD для продукции (можно начать с Flask-Admin для скорости, потом заменить своей).

7 Стилизация — подключить Bootstrap-шаблон, адаптировать под фирменный стиль.

8 Деплой — Docker-контейнер, Gunicorn + Nginx, переменные окружения для конфигов.
