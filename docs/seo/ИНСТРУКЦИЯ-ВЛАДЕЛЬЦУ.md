# Инструкция владельцу: регистрации и подключение

Это шаги, которые может сделать только владелец сайта (нужны ваши аккаунты, телефон, доступ к серверу). Всё остальное агенты делают сами. Интерфейсы сервисов меняются — если кнопка называется иначе, ищите по смыслу.

Порядок важен: сначала шаг 0, потом 1–3 (это даёт основу), остальное можно по мере времени.

## 0. Выложить фазу 0 на сервер (≈10 минут)

1. Проверьте и запушьте ветку `seo/phase-0` в GitHub (или скажите агенту «пушу» — когда у него будет доступ). Слейте её в `main` (Pull request или `git merge`).
2. На сервере (reg.ru):
   ```bash
   ssh u3602569@31.31.198.58
   cd /var/www/u3602569/data/www/himkom-ug.ru/
   git pull origin main
   touch tmp/restart.txt
   ```
3. Проверьте в браузере: https://himkom-ug.ru/robots.txt и https://himkom-ug.ru/sitemap.xml открываются (текст и XML, не ошибка).

## 1. Яндекс ID и Яндекс.Метрика

1. Если нет аккаунта Яндекса — создайте на https://id.yandex.ru (лучше отдельный, на компанию; запишите, на какую почту/телефон оформлен).
2. https://metrika.yandex.ru → **Добавить счётчик**: название «ХИМКОМ-ЮГ», адрес `himkom-ug.ru`. **Вебвизор не включайте** (на сайте нет политики конфиденциальности, а в формах персональные данные).
3. Скопируйте **номер счётчика** (только цифры, например `12345678`).
4. На сервере в файле `.env` (рядом с `passenger_wsgi.py`) добавьте строку:
   ```
   YANDEX_METRIKA_ID=12345678
   ```
   Затем `touch tmp/restart.txt`.
5. Проверьте: в Метрике, раздел «Проверка счётчика» (или «Код счётчика» → «Проверить»), покажет, что счётчик получает данные; зайдите на сайт, через 1–2 минуты в «Отчёты → Посещаемость» появится визит.
6. **Цели** (Метрика → Настройки → Цели → Добавить цель): «Клик по телефону» (тип «Составная» или JavaScript-событие — скажите агенту, он подготовит код), «Отправка формы». Настройку целей агент подготовит отдельным шагом — после п. 5 напишите ему «счётчик подключён».

## 2. Яндекс Вебмастер

1. https://webmaster.yandex.ru → **Добавить сайт** → `https://himkom-ug.ru`.
2. Подтверждение прав — выберите способ **«Мета-тег»**. Вебмастер покажет `<meta name="yandex-verification" content="КОД" />` — нужен только `КОД`.
3. На сервере в `.env`:
   ```
   YANDEX_VERIFICATION=КОД
   ```
   `touch tmp/restart.txt`, потом в Вебмастере **Проверить**.
4. После подтверждения: **Индексирование → Файлы Sitemap** → добавить `https://himkom-ug.ru/sitemap.xml`.
5. **Индексирование → Региональность**: Краснодарский край (или Краснодар).
6. **Индексирование → Переобход страниц**: отправьте главную, `/products/`, `/about`, `/contact`.

## 3. Google Search Console

1. https://search.google.com/search-console → **Добавить ресурс** → «Префикс URL» → `https://himkom-ug.ru/`.
2. Способ подтверждения — **«Тег HTML»**. Из `<meta name="google-site-verification" content="КОД" />` нужен `КОД`.
3. `.env` на сервере: `GOOGLE_VERIFICATION=КОД`, `touch tmp/restart.txt`, затем **Подтвердить**.
4. **Файлы Sitemap** → добавить `sitemap.xml`.

## 4. Яндекс Бизнес (Карты) и 2ГИС — локальное SEO

1. https://yandex.ru/sprav → добавить организацию: название «ХИМКОМ-ЮГ», адрес «г. Краснодар, пос. Дружелюбный, ул. Железнодорожная, 3», телефон `+7 952 868-45-67`, сайт `https://himkom-ug.ru`. Подтверждение — звонком или кодом от Яндекса. **Адрес и телефон должны совпадать с футером сайта буква в букву.**
2. https://account.2gis.com → «Добавить организацию» — те же данные.
3. Google Business Profile (https://business.google.com) — те же данные; подтверждение обычно открыткой или звонком.
4. Для карточек агент (`local-seo`) подготовит черновики описаний, рубрик и список фото — скажите «готовь карточки».

## 5. Доступ для автоматических отчётов (по желанию, делайте после п. 1–2)

Чтобы `analytics-reporter` сам брал цифры из Метрики и Вебмастера, нужен OAuth-токен. **Токен — секрет: не присылайте его в чат и не коммитьте.**

1. https://oauth.yandex.ru → **Создать приложение**, платформа «Веб-сервисы», Callback URL `https://oauth.yandex.ru/verification_code`, права: `Яндекс.Метрика: получение статистики, чтение параметров счётчика` и `Яндекс.Вебмастер: получение информации о сайтах`.
2. Получите токен по ссылке `https://oauth.yandex.ru/authorize?response_type=token&client_id=<ID_приложения>`.
3. Положите в переменные окружения того места, где будет работать расписание (см. п. 6): `YANDEX_OAUTH_TOKEN`, `YANDEX_METRIKA_ID`, `YANDEX_WEBMASTER_USER_ID`, `YANDEX_WEBMASTER_HOST_ID` (последние два видны в адресной строке Вебмастера).

## 6. Где запускать расписание — решение за вами

- **Облачные рутины Claude** (`/schedule`): не нужен свой сервер; но доступ к GitHub и секретам настраивается в облаке.
- **Cron на нашем сервере** (`claude -p "/seo-weekly"` раз в неделю): проще с токенами и локальным репозиторием, но сервер должен быть включён.

Скажите, какой вариант, — агент настроит.

## 7. Что нужно передать (файлы — в `docs/seo/data/`, не в чат с секретами)

- Технические листы и паспорта продуктов: Ф-3, Ф-1, ФП, ФК-20М, ФРОСТ 20, AERO — состав/тип, дозировка, расход, фасовка, ГОСТ/ТУ, сертификаты.
- Список приоритетных продуктов и регионов (куда реально возите).
- Реальные фото производства, склада, лаборатории (от 1600 px по ширине) — для шапок и карточек.
- Ссылки на Telegram и Max — когда каналы будут готовы (в футере пока заглушки `#`).
- Решение по политике конфиденциальности и баннеру о cookie (требования 152-ФЗ): без неё вебвизор и сбор форм лучше не расширять.
