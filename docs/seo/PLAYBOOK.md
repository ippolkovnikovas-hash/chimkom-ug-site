# Плейбук продвижения himkom-ug.ru

Единая инструкция для людей и SEO-агентов (`.claude/agents/`). Если правило здесь противоречит агенту — прав плейбук. Обновляется ежемесячно командой `/seo-monthly`.

## 1. Цель и допущения

- **Цель:** заявки (звонки, форма «Контакты», «Заказать звонок», WhatsApp) от производителей бетона и ЖБИ, строительных компаний и дилеров.
- **Регионы:** Краснодарский край, Ростовская область, Чечня, Дагестан, Ингушетия.
- **Поисковик:** основной — Яндекс; Google вторичен.
- **Бюджет:** рекламы и платных ссылок нет; только органика, контент, локальное SEO.
- **Допущения (подтвердить у владельца):** аудитория и регионы — как выше; конкуренты и частоты запросов ещё не измерены — это первая задача `keyword-researcher`.

## 2. Жёсткие правила (нарушать нельзя)

1. **Не выдумывать технические данные.** Дозировки, ГОСТ, сроки, сертификаты — только из материалов компании. Нет данных — пометка `TODO(заказчик): нужны данные` и вопрос в отчёте.
2. **Никакой «серой» оптимизации:** скрытый текст, переспам ключами, купленные ссылки и биржи ссылок, накрутка поведенческих факторов, дубли страниц под города, фейковые отзывы.
3. **Изменения сайта — только в ветках `seo/*` и через коммит.** `git push` и деплой — только после «пушу?» и ответа владельца. На сервер агенты не заходят.
4. **Секреты** (токены Метрики/Вебмастера, пароли) — только в `.env` на сервере или в переменных окружения расписания; в репозиторий, отчёты и чат не попадают.
5. **Персональные данные** посетителей не собирать и не выгружать. Вебвизор Метрики выключен, пока нет политики конфиденциальности.
6. **Контакты:** NAP (название, адрес, телефон) везде одинаковое — как в футере сайта. Любое расхождение — ошибка.
7. Firecrawl: кредиты ограничены, параллельно 2 задачи; перед `crawl`/`download`/`agent` оценить объём.

## 3. Семантическое ядро (стартовые кластеры)

Частоты и конкуренция **не измерены** — замерить через Яндекс Вордстат (Wordstat) и занести в `docs/seo/semantic-core.md`.

| Кластер | Примеры запросов (гипотезы) | Целевая страница |
|---|---|---|
| Суперпластификатор | суперпластификатор для бетона купить, пластификатор Ф-3, С-3 | продукты Ф-3, Ф-1, ФП |
| Противоморозные | противоморозная добавка для бетона, добавка для зимнего бетонирования | ФРОСТ, ФК-20М |
| Воздухововлекающие | воздухововлекающая добавка для бетона | AERO |
| Для ЖБИ и товарного бетона | добавки для ЖБИ, добавки для товарного бетона | категории каталога |
| Региональные | добавки для бетона Краснодар / Ростов / Махачкала / Грозный | главная, контакты, региональные страницы |
| Информационные | как работает пластификатор, дозировка противоморозной добавки | статьи (фаза 2) |

Правила: один кластер — одна главная страница; запросы каннибализируют друг друга — не делать две страницы под один смысл.

## 4. Страница продукта (шаблон, фаза 1)

URL `/products/<slug>`; `title` ≤ 60 симв., `description` 120–160 симв.; один `H1` с названием и типом добавки; блоки: назначение, эффект, дозировка, упаковка и фасовка, совместимость, сертификаты/ГОСТ, как заказать (телефоны по региону), FAQ. Текст — **настоящим HTML**, не картинкой (сейчас описания в каталоге — картинки, поисковик их не читает). Разметка `Product` — только с данными из материалов компании. Каждая страница добавляется в `SITEMAP_PAGES` (`app/main/seo.py`) и в перелинковку.

## 5. Чек-листы

**Техническое SEO** (`seo-auditor`): 200 на всех страницах sitemap; уникальные `title`/`description`/`H1`; canonical; `robots.txt` и `sitemap.xml`; HTTPS и редирект с http; нет битых ссылок; изображения с `alt` и разумным весом; адаптивность; скорость (LCP, размер страницы); отсутствие дублей (`www`/без `www`, слэш в конце).

**Локальное SEO** (`local-seo`): карточка в Яндекс Бизнесе (Яндекс Карты) и 2ГИС; Google Business Profile; одинаковые NAP; категории, описание, фото, ссылка на сайт; ответы на отзывы; карточки для офисов/ответственных по регионам — только если есть реальный адрес.

**Ссылки** (`link-builder`): только белые — отраслевые каталоги и справочники строительных материалов, профили на картах, партнёры и поставщики, региональные ассоциации, профильные СМИ. Заявки на размещение пишет владелец или с его разрешения; агент готовит список и черновики.

**Контент** (`content-writer`): фактура от компании; проверка по правилу №1; перелинковка со страницами каталога; метаданные; после публикации — запись в отчёт.

## 6. KPI и ритм

| Что | Источник | Как часто |
|---|---|---|
| Страницы в индексе | Яндекс Вебмастер | еженедельно |
| Показы, клики, позиции по кластерам | Вебмастер | еженедельно |
| Визиты по каналам, заявки (цели) | Метрика | еженедельно |
| Ошибки сайта, скорость | аудит + Вебмастер | ежемесячно |
| Рост по кластерам, пересмотр ядра | все | ежемесячно |

Цели Метрики (настроить после установки счётчика): отправка формы «Контакты», «Заказать звонок», клик по телефону, клик по WhatsApp. Ожидаемый срок первых результатов органики — 2–4 месяца; первые недели отчёты покажут в основном технические улучшения.

## 7. Фазы

- **Фаза 0 (сделана в коде):** robots, sitemap, мета-теги, canonical, Open Graph, JSON-LD, подключаемые Метрика и подтверждения. Ждёт регистраций владельца — `docs/seo/ИНСТРУКЦИЯ-ВЛАДЕЛЬЦУ.md`.
- **Фаза 1:** страницы продуктов — сделаны в коде 13.11.2026 (`/products/<slug>`, JSON-LD, sitemap). Не хватает данных от компании для блоков «совместимость», «сертификаты/ГОСТ на продукт», «фасовка», FAQ; семантическое ядро (Вордстат) — для уточнения title/H1.
- **Фаза 2:** региональные страницы (по реальному присутствию) и статьи.
- **Фаза 3:** расписание агентов и отчётов.

## 8. Процесс агентов

`/seo-weekly` → `analytics-reporter` (данные) → `seo-auditor` (проблемы) → `onpage-optimizer`/`content-writer` (правки в ветке `seo/<дата>-<тема>`) → отчёт в `docs/seo/reports/YYYY-MM-DD-weekly.md` со списком «что сделано / что требует решения владельца».
`/seo-monthly` → `keyword-researcher`, `local-seo`, `link-builder` → пересмотр ядра и этого плейбука.
Каждый агент заканчивает работу кратким итогом: файлы, проверки с результатом, что не проверено, что нужно от владельца.
