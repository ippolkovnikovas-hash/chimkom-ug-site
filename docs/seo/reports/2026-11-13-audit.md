## Требует решения владельца (затрагивает хостинг/деплой — сам не менял)
1. **Редирект http→https отдаёт 302** (временный) вместо 301. Правка в `.htaccess` (`[R,L]` → `[R=301,L]`); файл создан автоматически reg.ru при заказе SSL.
2. **Зеркало `www.himkom-ug.ru` отвечает 200 и не редиректит на основной адрес.** Дубль сайта (canonical спасает частично). Нужен 301 `www` → без `www` в `.htaccess` (сертификат на `www` есть, раз открывается) и «главное зеркало» в Вебмастере.
3. **Статика с `cache-control: no-cache`:** браузер каждый раз перепроверяет картинки, CSS и JS. Предложение: `max-age` 1 день для CSS/JS и 30 дней для картинок/шрифтов плюс версия в адресе (`?v=<дата изменения>`), чтобы правки не залёживались.
4. **Нет заголовков безопасности** (`Strict-Transport-Security`, `X-Content-Type-Options`, `X-Frame-Options`). Для SEO не критично; HSTS включать только после п. 1–2.
5. ~~Удалить файл `app/static/js/accordions.js`~~ — сделано (разрешение получено).
6. **Лёгкие шрифты/иконки:** Font Awesome 4.3 (старая версия) отдаёт 57 КБ woff2 — норма; Google Fonts подключены внешним запросом (можно положить локально, ускорит первый показ).
