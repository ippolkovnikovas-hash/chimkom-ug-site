Источник: выгрузки владельца (29 CSV, «топ частотных запросов», все устройства), лежат в `docs/seo/data/wordstat-2026-11/`.
Файлы названы `wordstat_top_queries (N).csv`; в первой строке каждого — запрос, период и регион.
Цифры — число запросов за месяц с учётом словоформ, как отдаёт Вордстат. Это спрос, а не посетители сайта.

Региональные страницы дадут немного прямого трафика; ставка на содержательные страницы и статьи, которые находят по всей России.

3. **Зимний сезон.** Период выгрузки — самый пик сезона противоморозных добавок; в остальные месяцы спрос ниже. Страницы ФРОСТ 20 и ФК-20М нужно усиливать сейчас, пока идёт зима.
4. **Название «Химком» занято другим.** По запросу «Химком» в Вордстате: «химка» 13 555 (город Химки), «гидрофобизатор для бетона химком» 165, «пропитка химком гидрофобизатор» 133, «пластификатор для бетона химком п2» 13. Это другая компания-однофамилец. Бренд ХИМКОМ-ЮГ напрямую почти не ищут (в Краснодарском крае 2 запроса). Вывод: в заголовках и описаниях бренд ставить вместе со словами «добавки для бетона» и «Краснодар», чтобы не потеряться на фоне «Химком».
5. **Большая часть спроса — розничная** («на ведро», «своими руками», «для теплого пола», «мыло»). Мы продаём еврокубами, значит наша аудитория — РБУ, заводы ЖБИ, подрядчики. Брать нужно запросы «купить», «оптом», «для товарного бетона», «для ЖБИ», «технические характеристики», «дозировка».

## Что делать (предложение, на решение владельца)
- **Страницы продуктов (уже есть):** добавить в тексты частые формулировки спроса. Ф-1/Ф-3/ФП — «суперпластификатор для бетона», «поликарбоксилатный суперпластификатор» (ФП), «дозировка». ФРОСТ 20/ФК-20М — «противоморозная добавка для бетона», «до −20°С», «купить». AERO — «воздухововлекающая добавка для бетона».
- **Статьи (фаза 2), от большего спроса к меньшему:**
  1. «Пластификатор и суперпластификатор для бетона: чем отличаются, какой выбрать» (9 755 + 2 607).
  2. «Противоморозные добавки для бетона: как выбрать и сколько добавлять» (823 + 172 + 139), выложить до пика зимы.
  3. «Сколько добавлять пластификатор в бетон» (386 + 237 + 205 запросов с вариантами).
  4. «Воздухововлекающие добавки: для чего нужны» (446 + 110).
  5. Гидроизоляция/водонепроницаемость (518 + 255) — только если у компании есть подходящий продукт; иначе пропустить.
- **Региональные страницы:** Краснодарский край (352–519 на главные запросы) стоит делать одной страницей «Добавки для бетона в Краснодаре и крае», Дагестан/Чечня/Ингушетия — одной страницей «Северный Кавказ» (спрос в сумме около 100). Отдельные страницы на каждый город не нужны.
- **Не брать:** запросы с названиями конкурентов (пенетрон, полипласт, cemplast, технониколь, фэс 50, д5) — сравнение без сертификатов и данных опасно.

## Чего не хватает
- Нет запросов с названиями продуктов (Ф-1, Ф-3, ФП, ФРОСТ 20, ФК-20М, AERO), «оптом», «для РБУ», «для ЖБИ», «Краснодар» в тексте запроса (а не фильтром региона). Эти данные нужны отдельной выгрузкой.
- Только топ-запросы, без динамики по месяцам и без «похожих запросов». Для зимнего сезона нужна динамика за год.
